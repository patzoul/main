This map reads live aircraft positions from the OpenSky Network. OpenSky blocks direct browser access, so it goes through a small free proxy you deploy once. Paste your proxy (Cloudflare Worker) URL:

No API key needed — OpenSky's anonymous tier is free, the proxy just adds the CORS header a browser requires (and caches responses so it stays well under OpenSky's daily anonymous quota). The URL is kept only in this browser's local storage. See open-data-proxy.js in the repo for the Worker code & setup steps.
